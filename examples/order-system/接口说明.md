# 订单接口说明 V1.0

## 查询
GET /api/orders/{id} 查询订单。查询需要登录，未登录返回401。普通用户查询他人订单返回403。不存在的订单返回404。列表接口GET /api/orders支持page和page_size，page_size最大100。

## 创建
POST /api/orders创建订单。请求体必须包含items和address_id。商品数量超出1到99返回400。库存不足返回409。创建成功返回201。

## 取消
POST /api/orders/{id}/cancel取消订单。请求体包含reason。取消成功返回200。已发货或已完成订单取消返回409。重复取消已取消订单返回200，保持幂等。越权取消他人订单返回403。

## 支付回调
POST /api/payments/callback接收支付回调。支付回调必须校验签名，签名无效返回403。回调使用payment_id去重。重复有效回调返回200，不重复改变订单状态。
