# 模拟订单系统使用手册 V1.0

## 下单
订单状态依次为待支付、待发货、已发货、已完成。创建订单必须包含至少一件商品。商品购买数量必须为1到99的整数。库存不足时下单失败，不生成订单。订单金额使用人民币，精确到分。

## 支付与时限
待支付订单30分钟未支付自动关闭。支付成功后进入待发货状态。已关闭订单不支持继续支付，用户需要重新下单。重复支付回调不得重复扣减库存。

## 取消与退款
待支付订单可由本人取消。待发货订单允许本人取消，取消后原路退款。已发货订单不支持取消。已完成订单不可取消。退款通常在3个工作日内到账，不承诺实时到账。取消成功会释放已占用的库存。

## 发货与售后
只有支付成功的订单才能发货。已发货订单需要收货后申请售后。用户确认收货后订单变为已完成。订单发货后不能修改收货地址。待发货订单允许本人修改收货地址。
