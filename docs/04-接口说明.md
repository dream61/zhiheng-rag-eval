# 当前接口说明

## 1. 通用约定

基础路径/api/，JSON请求；除health与token外须提供Authorization: Token <令牌>。列表分页结构为count、next、previous、results，每页50条。校验错误400、未登录401/403、资源不存在404、模型执行异常502、入队失败503。调试状态不可公开部署。

## 2. 接口清单

| 方法与路径 | 用途 |
| --- | --- |
| GET /api/health/ | 进程存活检查，不代表依赖服务健康 |
| POST /api/token/ | username/password换取开发令牌 |
| GET/POST /api/assets/ | 列表与创建草稿；kind参数筛选 |
| GET/PUT/PATCH /api/assets/{id}/ | 详情与编辑未发布草稿 |
| POST /api/assets/{id}/upload/ | multipart字段file上传文档 |
| POST /api/assets/{id}/publish/ | 校验并冻结发布 |
| POST /api/assets/{id}/chat/ | 指定已发布知识库调试问答 |
| GET/POST /api/experiments/ | 查询与创建实验 |
| GET /api/experiments/{id}/ | 实验详情与快照 |
| GET /api/experiments/{id}/results/ | 分页样本结果与复核历史 |
| GET /api/experiments/{id}/report/ | 执行、质量和待复核计数 |
| GET/POST /api/reviews/ | 查询和追加复核 |

## 3. 请求示例

创建知识库：

```json
{"kind":"knowledge","name":"订单知识库","product":"模拟订单系统","version":"v1.0","content":[{"name":"使用手册.md","text":"已发货订单不支持取消。"}],"settings":{"chunk_size":500,"overlap":80}}
```

创建数据集（JSON文件内容可直接作为请求体导入）：

```json
{"kind":"dataset","name":"订单基础评测","product":"模拟订单系统","version":"v1.0","content":[{"id":"order-001","question":"普通用户能取消已发货订单吗？","reference":"不能，已发货订单不支持取消。","evidence":[{"document":"使用手册.md","text":"已发货订单不支持取消。"}],"type":"权限规则","should_refuse":false,"required":["不支持取消"],"forbidden":[],"approved":false}],"settings":{}}
```

人工核对参考答案与证据后，将approved改为true再发布。当前通过资产编辑保存审核标记，尚无独立样本审核人日志，不能等同于最终审计验收。

创建实验：

```json
{"name":"Top K=3基线","knowledge":1,"dataset":2,"config":{"top_k":3,"backend":"mock","model":"qwen-plus"}}
```

问答：

```json
{"question":"已发货订单能取消吗？","top_k":3,"backend":"mock","model":"qwen-plus"}
```

复核：

```json
{"result":1,"passed":false,"reason":"证据已检索到，但回答遗漏限制条件","attribution":"生成遗漏"}
```

## 4. 结果与统计

trace包含answer、refused、citations、evidence、usage、latency_ms、backend。scores中的correctness和groundedness当前为空；passed=false表示规则已发现质量问题，passed=null表示需要人工语义复核。人工复核不覆盖scores字段。
