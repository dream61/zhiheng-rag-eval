## 3. 测试策略

pytest重点验证：非法样本拒绝、未审核禁止发布、已发布不可变、实验快照、重复投递、执行异常与质量失败区分、复核不覆盖原始评分、匿名请求禁止访问。Playwright首批为登录页面冒烟，后续扩展资产发布与实验复核完整流程。Locust用于已认证只读列表与报告并发，不触发付费模型调用。

## 4. 风险与限制

- 当前发布版本的约束依赖受控API和只读Admin，直写数据库不受业务冻结约束保护。
- 当前审核是样本布尔标记，尚无独立审批证据。
- Worker崩溃可能留在running；当前不自动恢复，后续通过租约处理。
- live首次惰性建索引存在并发竞争和部分写入风险，正式批量前必须完成异步索引发布。
- 规则仅检查结论字符串、证据原文覆盖和引用来源存在，不能代表语义评分；规则通过样本须人工复核。
- 当前前端展示首个分页，超过50条需补充翻页控件；目标验收50条适用。
- 模型端点与Embedding目前共用配置，独立供应商组合待接入。
